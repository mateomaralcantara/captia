# Prototipo de CAPTIA Control

`captia-prototipo.html` es una **maqueta** de cómo se verá el panel con todos los módulos construidos,
con 5 registros de ejemplo por módulo. Se abre en la **granja de teléfonos**: los 5 Android con su pantalla y, al pulsar uno, su consola (controles, datos y registro de operaciones). **No es el producto**: todos los datos son ficticios, los
botones no ejecutan acciones y cada pantalla lo indica.

Para verlo, abre el archivo con doble clic (se abre en el navegador). No necesita instalar ni
arrancar nada. Necesita internet solo para cargar las tipografías; sin conexión usa las del sistema.

El panel real (`apps/web`) nunca muestra datos de ejemplo: solo lo que existe de verdad.
